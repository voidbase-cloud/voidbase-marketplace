# Notice

The way this marketplace works is taken from
[omarchy-plugin-marketplace](https://github.com/omacom/omarchy-plugin-marketplace): submissions arrive as GitHub
issue forms, an automated pass reports on the repository before anyone decides, an explicit maintainer approval is
what lists it, and the registry is a JSON file in the repository rather than rows in a database. None of its code is
here and this is a much smaller version of the idea, but the shape is theirs and it is worth saying so.

Listed repositories belong to the people who wrote them, under whatever licence they chose. A listing is a pointer,
not a copy, and not an endorsement.
